# Импорт каталога и массовая проверка

## Формат файла
- CSV (UTF-8 или Windows-1251, разделитель `;`, `,` или табуляция определяется автоматически) и XLSX (читается первый лист).
- Первая строка — названия столбцов. Лимиты: 5 МБ, 2000 строк, 60 столбцов. Файл обрабатывается в памяти и не сохраняется.

## Поля
| Поле | Обязательно | Примечание |
|---|---|---|
| Название | да | до 255 символов |
| Артикул (SKU) | нет | до 120 символов, используется для поиска дублей |
| Маркетплейс | нет | Ozon/Озон, Wildberries/WB; иное значение → «другой» |
| Категория | нет | до 255 символов |
| Описание | нет | до 20 000 символов |
| Характеристики | нет | строки «Ключ: значение», разделители `:`, `=`, ` — `, ` - `, табуляция; до 40 строк |

Сопоставление столбцов предлагается по названиям, пользователь может изменить его вручную.

## Проверка строк
- `error` — нет названия или превышены длины.
- `duplicate` — артикул уже есть в рабочем пространстве или повторяется в файле; для строк без артикула — повтор названия внутри файла.
- Если есть проблемные строки, импорт без флага «пропустить некорректные» не создаёт ничего. Повторный импорт того же файла не создаёт дублей.

## API
- `POST /api/v1/products/import/preview` — предпросмотр и проверка (ничего не сохраняет).
- `POST /api/v1/products/import/commit` — создание товаров (поля `file`, `mapping`, `skip_invalid`).
- `GET /api/v1/products/export.xlsx` — листы «Сводка», «Товары», «Находки».

## Пакетная проверка
Выполняется на странице «Товары»: выбранные товары проверяются по одному существующим методом запуска анализа. Ошибка одного товара не останавливает остальные, неудачные остаются выбранными для повтора. Новых таблиц и фоновых задач нет, поэтому закрытие вкладки прерывает очередь; уже проверенные товары сохраняются.
